# Portfolio de Julien Rodrigues

Petit site statique réalisé avec **HTML et CSS**. Il comprend quatre pages : accueil, projets, parcours et contact. Aucun outil de compilation ni installation de dépendance n'est nécessaire.

## Fichiers

```text
index.html                 Page d'accueil (obligatoire pour GitHub Pages)
projets.html               Projets de formation
parcours.html              Formations et compétences
contact.html               Adresse de contact
assets/css/style.css       Mise en forme des quatre pages
DEFENSE.md                 Préparation de l'oral
```

## Ouvrir le site sur son ordinateur

Décompressez l'archive. Ouvrez le fichier `index.html` dans un navigateur, ou ouvrez le dossier dans VS Code et utilisez Live Server. Cliquez sur les liens du menu pour parcourir les quatre pages.
